## Описание проекта

Этот проект представляет собой современную e-commerce платформу, построенную по микросервисной архитектуре с использованием контейнеризации Docker. Система состоит из трех основных компонентов:

### Архитектура проекта

```
┌─────────────────────────────────────────────────────────────┐
│                     NGINX (Порт 8000)                       │
│                    Веб-сервер / Роутер                      │
└───────────────────┬─────────────────────────────────────────┘
                    │
        ┌───────────┴───────────┐
        │                       │
        ▼                       ▼
┌───────────────┐       ┌───────────────┐
│   Backend API │       │  Frontend Apps│
│   (Laravel)   │       │  (Vue.js)     │
│   PHP 8.2+    │       │               │
└───────┬───────┘       └───────┬───────┘
        │                       │
        │                       ├─── Admin App (Админ-панель)
        │                       │
        │                       └─── Public App (Публичный сайт)
        │
        ▼

│   MySQL 8.0   │

│   (Порт 3307) │

        │
        ▼

│  PHPMyAdmin   │
```

## Компоненты системы

### 1. Backend (Laravel API) - "Мозговой центр"

**Путь:** `/backend`  
**Технологии:** 
- Laravel 12.0 (PHP 8.2+)
- Laravel Sanctum (аутентификация)
- MySQL 8.0
- Docker

**Основные возможности:**
- RESTful API для всех операций
- Аутентификация и авторизация (Sanctum)
- Управление пользователями и ролями (User, Admin, Seller)
- CRUD операции для товаров
- Управление категориями (с поддержкой вложенности)
- Система заказов
- Управление атрибутами товаров
- Обработка изображений и медиа-файлов
- Поддержка видео для товаров

**Основные модели:**
- `User` - пользователи системы
- `Product` - товары (с изображениями, видео, атрибутами, категориями)
- `Category` - категории товаров (древовидная структура)
- `Order` - заказы
- `Role` - роли пользователей
- `Attribute` - атрибуты товаров (размер, цвет и т.д.)
- `AttributeOption` - варианты атрибутов

**API эндпоинты:**
- Публичные маршруты (без аутентификации):
  - `GET /api/products` - список товаров
  - `GET /api/products/popular` - популярные товары
  - `GET /api/products/newest` - новые товары
  - `GET /api/products/{id}` - детали товара
  - `GET /api/categories` - список категорий
  - `POST /api/orders/public` - создание заказа (публичное)

- Защищенные маршруты (требуют аутентификации):
  - `GET /api/user` - текущий пользователь
  - CRUD для товаров (для администраторов/продавцов)
  - CRUD для категорий (для администраторов)
  - CRUD для пользователей (для администраторов)
  - CRUD для ролей (для администраторов)
  - CRUD для заказов (для администраторов)
  - CRUD для атрибутов (для администраторов)

**Особенности:**
- Многопользовательская система с разграничением прав
- Продавцы видят только свои товары
- Администраторы имеют полный доступ ко всем данным
- Поддержка множественных изображений для товара (JSON)
- Видео-ссылки для товаров
- Система атрибутов привязана к категориям
- Поддержка основной и дополнительной категории для товара
- Свойства товаров хранятся в JSON формате

### 2. Admin App - "Кабинет директора"

**Путь:** `/admin-app`  
**Технологии:**
- Vue.js 3.5
- Vuetify 3.9 (Material Design UI)
- Vue Router 4.5
- Pinia (управление состоянием)
- Axios (HTTP клиент)
- Vite (сборщик)

**Назначение:**
Административная панель для управления всеми аспектами магазина:
- Управление товарами (добавление, редактирование, удаление)
- Управление категориями
- Управление пользователями
- Управление ролями
- Просмотр и обработка заказов
- Управление атрибутами товаров
- Загрузка изображений и видео

**Интерфейс:**
- Современный Material Design интерфейс
- Адаптивный дизайн
- Удобная навигация
- Формы с валидацией
- Таблицы с сортировкой и фильтрацией

### 3. Public App - "Витрина магазина"

**Путь:** `/public-app`  
**Технологии:**
- Vue.js 3.5
- Vuetify 3.9
- Vue Router 4.5
- Pinia
- Axios
- Vite

**Назначение:**
Публичный сайт для покупателей:
- Просмотр каталога товаров
- Поиск и фильтрация товаров
- Просмотр категорий
- Детальная страница товара (с изображениями и видео)
- Оформление заказа
- Регистрация и вход пользователей

**Интерфейс:**
- Привлекательный дизайн для покупателей
- Удобная навигация по категориям
- Карточки товаров
- Корзина покупок
- Оформление заказа

**Порт:** 5174 (через docker-compose)

### 4. Инфраструктурные компоненты

#### NGINX (Порт 8000)
- Веб-сервер и обратный прокси
- Маршрутизация запросов к Laravel backend
- Обслуживание статических файлов

#### MySQL 8.0 (Порт 3307)
- Основная база данных
- Хранение всех данных приложения
- Персистентное хранилище (volume: db-data)

#### PHPMyAdmin (Порт 8081)
- Веб-интерфейс для управления базой данных
- Удобный инструмент для разработки и отладки
- Доступ: http://localhost:8081

## База данных

### Основные таблицы:
- `users` - пользователи
- `roles` - роли
- `role_user` - связь пользователей и ролей (многие-ко-многим)
- `products` - товары
- `categories` - категории (с parent_id для вложенности)
- `orders` - заказы
- `order_product` - связь заказов и товаров (многие-ко-многим)
- `attributes` - атрибуты товаров
- `attribute_options` - варианты атрибутов
- `attribute_category` - связь атрибутов и категорий
- `personal_access_tokens` - токены для API (Sanctum)
- `cache`, `jobs` - системные таблицы Laravel

## Как работать с проектом

### Запуск проекта

```bash
# Запуск всех сервисов
docker-compose up -d

# Остановка сервисов
docker-compose down
```

### Доступ к сервисам
- **Backend API:** http://localhost:8000
- **Admin Panel:** http://localhost:5173 (dev mode)
- **Public Site:** http://localhost:5174 (dev mode)
- **PHPMyAdmin:** http://localhost:8081

### Backend разработка

```bash
# Войти в контейнер backend
docker exec -it ecom_app bash

# Установка зависимостей
composer install

# Миграции базы данных
php artisan migrate

# Создание тестовых данных
php artisan db:seed

# Запуск тестов
php artisan test

# Форматирование кода
./vendor/bin/pint
```

### Frontend разработка (Admin App)

```bash
# Войти в контейнер admin-app
docker exec -it ecom_admin_app sh

# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build
```

### Frontend разработка (Public App)

```bash
# Войти в контейнер public-app
docker exec -it ecom_public_app sh

# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для production
npm run build
```

### Как добавлять новые функции:

1. **Backend (API):**
   - Создать миграцию: `php artisan make:migration create_xxx_table`
   - Создать модель: `php artisan make:model Xxx`
   - Создать контроллер: `php artisan make:controller Api/XxxController`
   - Добавить маршруты в `/backend/routes/api.php`
   - Добавить policy для авторизации (при необходимости)

2. **Frontend (Admin/Public):**
   - Создать Vue компонент в `/src/components/`
   - Создать представление в `/src/views/`
   - Добавить маршрут в `/src/router/`
   - Создать store в Pinia (при необходимости) в `/src/stores/`
   - Добавить API вызовы в `/src/api.js`

3. **Тестирование:**
   - Backend: создать тесты в `/backend/tests/`
   - Frontend: создать unit/integration тесты
