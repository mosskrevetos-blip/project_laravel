## 📋 О проекте

Современная полнофункциональная платформа электронной коммерции (интернет-магазин), построенная по микросервисной архитектуре с использованием контейнеризации Docker.

### Ключевые особенности

✨ **Разделение на модули:**
- 🔧 **Backend API** (Laravel) - RESTful API для всех операций
- 👨‍💼 **Admin Panel** (Vue.js) - Административная панель управления
- 🛍️ **Public Site** (Vue.js) - Публичный сайт для покупателей

🔐 **Безопасность:**
- Аутентификация через Laravel Sanctum
- Разграничение прав доступа (Admin, Seller, User)
- Защита от SQL-инъекций и CSRF атак

🚀 **Производительность:**
- Docker контейнеризация для легкого развертывания
- Оптимизированные запросы к базе данных
- Современный стек технологий

## 🎯 Назначение проекта

Этот проект создан для:
- 🛒 Управления интернет-магазином с полным функционалом
- 📦 Управления товарами, категориями и заказами
- 👥 Управления пользователями и их ролями
- 📊 Обработки заказов и отслеживания продаж
- 🎨 Настройки атрибутов товаров по категориям

## 🚀 Быстрый старт

### Минимальные требования
- Docker Desktop
- Docker Compose
- Git

### Запуск в 3 команды

```bash
# 1. Клонировать репозиторий
git clone https://github.com/mosskrevetos-blip/project_laravel.git
cd project_laravel

# 2. Запустить Docker контейнеры
docker-compose up -d

# 3. Инициализировать backend
docker exec -it ecom_app bash -c "composer install && php artisan key:generate && php artisan migrate && php artisan db:seed"
```

### Доступ к сервисам

- 🌐 **Backend API:** http://localhost:8000
- 👨‍💼 **Admin Panel:** http://localhost:5173
- 🛍️ **Public Site:** http://localhost:5174
- 🗄️ **PHPMyAdmin:** http://localhost:8081 (root/root)

## 📖 API Эндпоинты

### Публичные (без авторизации)
```
GET    /api/products              # Список товаров
GET    /api/products/{id}         # Детали товара
GET    /api/products/popular      # Популярные товары
GET    /api/products/newest       # Новые товары
GET    /api/categories            # Список категорий
POST   /api/orders/public         # Создание заказа
```

### Защищенные (требуют токен)
```
GET    /api/user                  # Текущий пользователь
POST   /api/products              # Создать товар
PUT    /api/products/{id}         # Обновить товар
DELETE /api/products/{id}         # Удалить товар
GET    /api/orders                # Список заказов (Admin)
POST   /api/categories            # Создать категорию (Admin)
GET    /api/users                 # Список пользователей (Admin)
```

Полная документация API: [API_DOCUMENTATION.md](API_DOCUMENTATION.md)

## 👨‍💻 Разработка

### Полезные команды

```bash
# Backend
docker exec -it ecom_app bash
php artisan migrate
php artisan test
./vendor/bin/pint

# Admin App
docker exec -it ecom_admin_app sh

npm run build

# Public App
docker exec -it ecom_public_app sh
npm run dev
npm run build

# Логи
docker-compose logs -f
docker-compose logs -f app

docker-compose restart
```
