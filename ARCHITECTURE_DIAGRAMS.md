## Жизненный цикл запроса

```
1. Browser Request
   │
   ▼
2. NGINX (Port 8000)
   │
   │ [Routing]
   │
   ├──► /api/* ──────────┐
   │                     │
   └──► / ──────┐        │
                │        │
                ▼        ▼
3a. Static Files  3b. Laravel PHP-FPM
    (public/)         │
                      │ [Middleware Stack]
                      │ - CORS
                      │ - Auth (Sanctum)
                      │ - Throttle
                      │
                      ▼
                  4. Routes (api.php)
                      │
                      ▼
                  5. Controller
                      │
                      ▼
                  6. Model (Eloquent)
                      │
                      ▼
                  7. MySQL Query
                      │
                      ▼
                  8. Response JSON
                      │
                      ▼
9. Browser receives JSON
   │
   ▼
10. Vue.js renders UI
```

## Легенда символов

- `│` `─` `┌` `└` `┐` `┘` `├` `┤` `┬` `┴` `┼` - рамки и соединения
- `▼` `▲` - направление потока вниз/вверх
- `►` `◄` - направление потока вправо/влево
- `┐` `┘` `└` `┌` - углы
- `M:M` - связь многие ко многим
- `1:M` - связь один ко многим
- `M:1` - связь многие к одному
